# Winter art provenance

Created with the built-in image-generation tool for Ambros Journey. Final PNGs are in `capstone/Assets/WinterLevel/Art/`. Transparent alpha is retained. Unity import settings control the runtime sprite scale and resolution; originals are retained in the repository.

## CaveEntrance.png

Create a production game sprite: one snow-covered cave entrance for a top-down 2D pixel-art fantasy RPG. Actual transparent background. Isolated complete object, no ground rectangle, no text, no UI, no characters. Three-quarter top-down view like classic 16-bit woodland RPG tiles: visible upper surfaces, front-facing dark cave mouth opening toward bottom. Large rugged slate-blue rock outcrop with thick white snow on ledges, small icicles, crisp chunky pixel clusters, limited harmonized blue-grey and ivory palette, warm tiny amber lantern hanging beside the entrance, restrained cyan ice accents. Cave opening black navy, broad and clearly walkable. Snowy pine sapling on one side. Entire object within frame with transparent margin, approximately square sprite. High quality handcrafted pixel-art aesthetic, crisp hard edges, no painterly blur, no realistic texture, no outlines too heavy. Designed to match existing Mana Seed snowy forest tiles and small fantasy sprite characters. Single cave entrance object only.

Crisp chunky pixel clusters with limited slate blue, cyan, pale icy white palette; 16-bit SNES / Mana Seed aesthetic. Three-quarter elevated view, visible crystal upper facets, small dark rocky base, five angular ice crystals of varied heights, largest central, tiny chips at base. Elegant rich faceted shading, sharp distinct silhouette, no bloom outside silhouette, no text, no frame, no ground tile, no characters. Entire object centered with generous transparent margins. Game-ready crystal prop matching a snowy cavern with warm lanterns.

Dark timber post, small hanging iron lantern with golden glass light, snow cap, a few crisp ice pixels, restrained blue slate shadows and ivory snow.
